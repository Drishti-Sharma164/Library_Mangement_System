# Library Management System

A modular library management application developed in C++17 using Object-Oriented Programming.

### Features
- Book management
- Student management
- Book issue and return
- Fine calculation
- Search and filtering
- Transaction records
- File-based data storage

### Tech Stack
- C++17
- Object-Oriented Programming
- File Handling
- Embarcadero Dev-C++

### Project Structure
- `include/` – Header files
- `src/` – Source files
- `data/` – Data storage

### Build
Compile the nine source files in `src/` using a C++17-compatible compiler. Add `include/` to the compiler's header search path.
